# Fonts

Self-hosted (latin and latin-ext subsets, woff2), the same files as the web dashboard
(zen-hub `src/assets/web/fonts/`), so the app loads nothing from another origin. All are under the
SIL Open Font License 1.1 (https://openfontlicense.org):

- Young Serif, Copyright 2023 The Young Serif Project Authors (page titles).
- Hanken Grotesk, Copyright 2021 The Hanken Grotesk Project Authors (text on Registru pages).
- IBM Plex Mono, Copyright 2017 IBM Corp. (labels inside data).
