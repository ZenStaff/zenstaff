## The first version is a draft

The agent rarely gets it right the first time, and that is fine. What matters is how you ask for the next version.

"Not good, try again" gives you a different text with different problems. A precise correction gives you the same text, fixed.

Stay in the same thread for corrections. The agent remembers your request, the files and what it already tried, so you don't have to explain everything again.

:::picture iterate
Each precise correction leads to a better version: v1, v2, v3.
:::

## Point to the part and protect what works

**Point to the exact part.** Quote it or name it: "the second paragraph", "the sentence starting with 'We apologise'", "the title". Not "the middle part is weird".

**Say what to keep.** When you ask for one change, the agent tends to rewrite everything. Protect what works: "Keep the title and the last sentence exactly as they are."

:::dont
"Not really what I wanted, make it better and more professional."
:::

:::do
"In anunt-formal.md, the first sentence is too long. Split it in two. Keep 'Starting 1 December' at the very beginning, because that is what people look for first. Don't change anything else. Save it as anunt-formal-v2.md."
:::

## The reason, one at a time, in a new file

**Give the reason.** "Shorter, because it goes on an Instagram story" helps more than "shorter". When it knows the reason, the agent chooses on its own what to cut.

**One change at a time.** If you send five corrections at once, some get lost or half done. Send the most important one, check, then the next.

**Ask for a new file.** "Save it as anunt-v2.md, don't overwrite the first one." That way you can compare and go back if the new version is worse.

## When to start over

Correcting in the same thread works well up to a point. Start a new thread when:

- after three or four rounds it keeps coming back to the same mistake;
- you changed your mind about the task itself (different audience, different format);
- the thread got very long and the agent starts forgetting what you said at the start;
- you want an honest second opinion on the result.

:::tip
When you start over, don't lose what you learned. Write a new, complete request that includes the corrections from the old thread: "Under 40 words, 'Starting 1 December' first, no apologies."
:::

## A habit that saves time

When a correction works, note it.

If you keep writing "no exclamation marks" or "use 'you' informally", that line belongs in your first request next time, or in a card (see the lesson on creating your own workflow).
