## The agent only knows what you tell it

A new colleague who gets "make an announcement about the holiday schedule" will ask: for whom? where does it go? what are the hours?

The agent often does not ask. It fills the gaps with plausible guesses and hands you something generic that fits everywhere and nowhere. A good request removes the guessing.

:::dont
"Make a nice announcement about the holiday schedule."
:::

:::do
You say who it is for, the exact hours, the tone you want and where to save the result.
:::

## Five things a good request contains

1. **Context: who you are, who it is for, why.** "I work in marketing at a bakery with two shops in Brașov. This is for our regular customers, so they don't find the door closed on 25 December."
2. **The facts.** Hours, dates, prices, names. Write them down or point to a file: "the hours are in program-sarbatori.csv".
3. **An example.** "Same tone as last year's Easter post, pasted below." One example beats ten adjectives.
4. **Limits.** "Under 80 words, friendly, no exclamation marks, don't mention prices."
5. **What done looks like.** "Save it as anunt-sarbatori.md, with a title and the text, ready to paste into Facebook."

:::warn
Never let the agent make facts up. You give it the hours, dates and prices.
:::

## A good request, in full

This is what the five things look like together.

:::example The full request
I handle Facebook for Boabe Bune, a cafe with two locations in Brașov.
Write an announcement for our customers about the holiday hours.
Hours: 24 Dec 8-14, 25-26 Dec closed, 31 Dec 8-16, 1-2 Jan closed, from 3 Jan normal hours. Same hours in both locations.
Friendly tone, under 80 words, no emoji, end with "See you soon".
Save it as anunt-sarbatori.md.
:::

This one takes one extra minute to write. It saves you three rounds of corrections.

## One task per message

"Write the announcement, translate it to English, make three Instagram versions and email it to Mihaela" is four tasks. The agent does all of them half well, and you no longer know which part to fix.

:::dont
Four tasks in a single message.
:::

:::do
Ask for one, check it, then ask for the next in the same thread.
:::

:::tip
The agent remembers the earlier steps in the same thread. You don't have to repeat everything.
:::

## Let it ask you first

When you are not sure what you need yourself, end your message with the sentence below.

:::example The closing sentence
"Before you start, ask me the questions you need answered. Wait for my answers."
:::

The agent tells you what is missing: the audience, the dates, the tone. Answering a few questions is usually faster than writing a perfect request from scratch. And you see right away what you forgot.

:::picture chat
The agent asks you numbered questions and waits for your answer.
:::

## Try it now

:::try
You open a practice folder with a vague request from a manager: "make a short, nice announcement about the holiday schedule". The agent asks you 3 to 5 questions before writing anything, and creates no file. Answer them with made-up details, then let it write the announcement.
:::

:::quiz
You ask the agent for an announcement and get a generic text that would fit any company. What was most likely missing?

- [ ] A more polite message.
- [ ] A more expensive AI model.
- [x] The context and the exact facts: who it is for, which hours, what tone.

> The agent fills gaps with plausible guesses. The more precise you are, the less it guesses.
:::

:::quiz
You need the announcement written, translated into English and turned into Instagram versions. How do you go about it?

- [x] Ask for the announcement, check it, then ask for the translation and the versions one by one, in the same thread.
- [ ] Put all three in one message to finish faster.
- [ ] Open three different threads and start from zero in each.

> One task per message shows you clearly what needs fixing, and the agent remembers the earlier steps.
:::

:::quiz
You don't know exactly what information the agent needs for a task. What do you do?

- [ ] Let it start and see what comes out.
- [x] Ask it to put its questions to you first and wait for your answers.
- [ ] Put the task off until you have figured it all out alone.

> Answering a few questions is faster than writing a perfect request on the first try.
:::
