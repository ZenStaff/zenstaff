## Why you check every time

An agent's text reads well even when it is wrong. That is the trap.

It can write "Tuesday, 26 November" when the 26th is a Thursday. It can use last year's price, add a discount nobody approved, or greet the client by the wrong name. None of it looks suspicious. It is just wrong, and the client will notice before you do.

:::tip
Treat everything the agent writes as a draft from a smart intern on their first day: useful, fast, and in need of checking.
:::

## What to look for

Go through the text with these questions:

- **Numbers.** Does every price, quantity and total match the source file? Recompute at least one total yourself.
- **Names.** Client, contact person, company, products. A wrong name is the most embarrassing mistake.
- **Dates.** Does the day of the week match the date? Is it the right year?
- **Quotes.** Did that person actually say this? Did they agree to be quoted?
- **Links and addresses.** Open every link. The agent sometimes writes addresses that do not exist.
- **Promises.** "Free delivery", "guaranteed", "the best in the county". Is anyone in your company prepared to stand behind that?
- **Tone.** Is this how your company talks to this client?
- **Personal data.** Another client's name, a phone number, an internal note that should not reach this person?

:::picture check
You check the result against the source. The wrong number stands out.
:::

## Let the agent help you check

The agent is better at checking than at writing from nothing, as long as you give it the source. Ask it directly:

:::example A checking request
"Act as a strict editor. Compare oferta.md with preturi.csv. List every claim that is wrong or that you cannot verify from the files: the sentence, what is wrong, what the file says. Do not edit anything."
:::

Two useful habits:

- Ask for **the list of what it cannot verify**. Anything on that list you either remove or confirm yourself.
- Do **a second check in a new thread**.

:::dont
You ask it to check its own text in the same thread. The agent tends to defend it.
:::

:::do
You open a new thread and tell it "you are a strict editor". There it is much harsher.
:::

## Read the file, not the summary

When it finishes, the agent often says something like "Done, I wrote the offer with all the prices from the list."

That sentence is a summary, not proof. Open the file and read it. The summary and the file can say different things, and only the file goes to the client.

:::dont
You trust "Done, I put in all the prices" and send it.
:::

:::do
You open the final file and read it yourself, line by line.
:::

## The five-minute routine

Before you send anything the agent wrote:

1. Open the final file.
2. Check names and dates by eye.
3. Recompute one total.
4. Ask for the list of what cannot be verified.
5. Read the text once as if you were the client.

:::warn
Wrong prices, discounts and promises cost money. On an offer, do not skip a step.
:::

## Try it now

:::try
You open a practice folder with an offer email draft and a price list. The draft has several hidden mistakes. The agent reads it as a strict editor and lists them, without changing anything. Before you look at its answer, try to find them yourself, then compare.
:::

:::quiz
The agent writes "Done, I put all the prices from the list in the offer." What do you do before sending?

- [ ] Send it, since it confirmed.
- [x] Open the file and check the prices against the list.
- [ ] Ask it in the same thread whether it is sure.

> The agent's message is a summary, not proof. The file is what goes to the client, so that is what you read.
:::

:::quiz
You want the agent to check an offer it wrote itself. Which way is better?

- [ ] Ask it in the same thread to look again.
- [ ] Don't ask it at all, check only by yourself.
- [x] Open a new thread, give it the offer and the source, and ask it to act as a strict editor.

> In the same thread the agent tends to defend its text. In a new one it is much more critical.
:::

:::quiz
The offer says "Tuesday, 26 November". What do you check?

- [x] Whether that date really falls on a Tuesday, and whether the year is right.
- [ ] Only whether "November" is spelled correctly.
- [ ] Nothing, dates do not matter in an offer.

> The agent often mixes up the day of the week and the date. It is one of its most common mistakes.
:::
