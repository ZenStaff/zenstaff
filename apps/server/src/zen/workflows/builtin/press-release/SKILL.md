# The press kit

Write everything in `press-kit/` in this folder. Details for each file are in `{{workflow_folder}}/references/kit.md`; read it before writing.

1. `press-release-ro.md` and/or `press-release-en.md` (by the languages chosen). The English version is a native rewrite for international or English-language media, not a word-for-word translation: same facts and quote, local references explained, dates and numbers in English format.
2. `pitch-email-ro.md` / `pitch-email-en.md`: subject line (under 70 characters, the news, no "PRESS RELEASE" shouting), a 100 to 130 word personal email, a plain-text version, and one follow-up message for 3 working days later.
3. `fact-sheet.md`: the key facts in one page (what, when, where, who, numbers, links, contact), only from the answers and sources.
4. `media-kit-checklist.md`: what to include, what exists already in the assets folder (when given) and what is missing.
5. `media-list.csv` and `distribution-guide.md`: the template and how to send responsibly. When a media list was given, check it as described in the reference file and write `media-list-checked.csv` plus a short summary.

Rules: never send email, never submit forms, never sign up anywhere. Never invent journalists or email addresses: the template has example rows marked `EXAMPLE`, and real rows come only from the person's list.
